# مفاتيح تفاعلية / Interactive Switches

حزمة مكوّنات سلة تحتوي على قسم مقارنة تفاعلي واحد بأربعة أشكال مفاتيح: شمس ونجوم، شمس وهلال، تشغيل وإيقاف، وليل هادئ. يستطيع التاجر إضافة القسم أكثر من مرة، واختيار الشكل والنصوص والرابط لكل نسخة.

## الوظيفة

المفتاح يبدّل بين نصين داخل القسم نفسه. لا يغيّر إعدادات المتجر أو أزرار «أضف للسلة» العامة. يمكن إضافة رابط اختياري إلى منتج أو صفحة.

## التطوير

```sh
pnpm install
pnpm build
pnpm dev
```

تعريف الحزمة وحقول التخصيص في `twilight-bundle.json`، والمكوّن في `src/components/interactive-switch/index.ts`.

## تجربة التاجر

1. أضف «مقارنة تفاعلية» من محرر الصفحة.
2. اختر شكل المفتاح من الخيارات الأربعة.
3. اكتب العنوان ونصوص الحالتين، ويمكنك وضع رابط اختياري.
4. أضف القسم مرة أخرى إذا أردت عرض شكل ثانٍ في الصفحة نفسها.
